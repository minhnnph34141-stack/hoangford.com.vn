HUONG DAN CAP NHAT HOANG FORD AUTO

1. Sao luu project hien tai tren GitHub.
2. Thay noi dung src/App.jsx bang file src/App.jsx trong goi nay.
3. Thay noi dung src/styles.css bang file src/styles.css trong goi nay.
4. Thay noi dung src/main.jsx bang file src/main.jsx trong goi nay.
5. Co the thay index.html va package.json neu project dang dung Vite + React.
6. Chay npm install (neu can), sau do npm run dev de kiem tra; npm run build de build.

Luu y: Form hien mo ung dung email bang mailto, chua luu lead vao database/Google Sheets.
Anh dang la anh minh hoa tu Unsplash, can thay bang anh xe Ford dung mau va co quyen su dung.
Gia va thong so chua duoc xac nhan; code de hien thi 'Lien he bao gia' va ghi chu can xac nhan theo xe.
